本業は Java、フロントは Vue です。だから個人ブログを作ろうと決めたとき、最初に浮かんだのは Vue で一気に片づけることでした。Vite で立ち上げ、vue-router でルーティング、記事は Markdown に置いてプラグインでコンポーネントへ。どの手順も手に馴染んでいます。

結局そうはしませんでした。ブログとは要するに**ほとんど変わらない文書の集まり**で、訪れた人は読んで去っていきます。そういう内容のために SPA を走らせるのは、訪問者全員にまずランタイムをダウンロードさせ、ブラウザ上でページを組み立てさせるということです。読者が欲しいのは文章なのに、こちらが先に渡すのはアプリケーションになってしまう。

いろいろ調べたうえで Astro を選びました。決め手は三つです。

## 一、既定で JavaScript ゼロ

Astro のコンポーネントは JSX のように書けますが、既定では**ビルド時にしか**動かず、出力は素の HTML と CSS です。明示的に求めない限り、ページに JavaScript は一行も入りません。

```astro title="src/pages/index.astro"
---
// ここのコードはビルド時にだけ走る。ブラウザからは見えない
const posts = await getCollection('posts')
---
<ul>
  {posts.map((post) => <li><a href={`/posts/${post.id}`}>{post.data.title}</a></li>)}
</ul>
```

本当に操作が必要な場所 —— たとえばトップページで実際に曲が鳴る音楽カード —— には別途 `<script>` を書き、Astro が小さなモジュールにまとめてくれます。既定は静的、必要な分だけ動的。この方向はブログの性質とぴったり合っています。

## 二、コンテンツコレクションに型がある

記事は `src/content/posts/` 配下の Markdown ファイルに置き、スキーマを一枚添えます。

```ts title="src/content.config.ts"
const posts = defineCollection({
  loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/posts' }),
  schema: ({ image }) =>
    z.object({
      title: z.string(),
      date: z.coerce.date(),
      tags: z.array(z.string()).default([]),
      cover: image().optional(),
      draft: z.boolean().default(false),
    }),
})
```

front matter の項目が足りなかったり日付の書式を間違えたりすると、ビルドがそのまま失敗し、どのファイルかを教えてくれます。Java を書く人間は、この「コンパイル時に間違いを止めてくれる」感覚に抗えません。`image()` は表紙画像を Astro の画像パイプラインにつなぎ、ビルド時に圧縮してレスポンシブなサイズまで生成します。

## 三、成果物はどこに置いてもいい

`pnpm build` が出すのは `dist/` というフォルダで、中身は HTML と CSS と画像です。Nginx でも、オブジェクトストレージでも、どんな静的ホスティングでも配れます。生かしておく Node のプロセスもなく、コールドスタートもなく、上げ続けるサーバー側の依存もありません。

> 静的サイト最大の運用上の利点は、運用が存在しないことです。

## 選ばなかったものと、その理由

- **Next / Nuxt**：能力が過剰でした。SSR もミドルウェアも API ルートも一つも使わないのに、そのために Node の動く機械を維持することになります。
- **Hexo / Hugo**：テーマの生態系は見事ですが、この画面は自分で一対一に描いたもので、ピクセル単位まで把握しておきたい。テンプレート言語を直すのはコンポーネントを直すほど素直ではありません。
- **手書きの HTML**：真剣に検討しました。諦めたのは、画像の自動圧縮とコンテンツのスキーマ検証が欲しかったからです。この二つを手で維持するのはつらすぎます。

いいねや閲覧数のように、どうしても動的でなければならないものは静的サイト単体では扱えません。あとで Go で小さなサービスを書いたので、それは別の記事に。
