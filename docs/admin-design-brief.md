# 管理台设计稿需求清单

给设计用的功能清单。当前 `/admin` 已经能用，但穿的是临时皮肤（借用博客的
token 快速拼的），**正式 UI 等你的 Pencil 稿出来后按稿 1:1 重做**。

布局、结构、视觉全由你定 —— 这份清单只约定「每页必须放得下哪些东西」，
字段一个都不能少（它们和后端接口一一对应）；顺序、分组、样式随你重排。

建议画板：桌面 1440 宽（内容列现在用的 max 1080，可改）。移动端可以先不画，
但如果画了移动版我也照做。明暗两套（沿用博客的明暗变量最省事，也可以另起一套）。

---

## 页面一：登录

- 口令输入框（password）
- 「进入」按钮
- 错误反馈（口令不对 / 连不上服务 / 尝试次数超限）——现在用 toast，可改行内
- 一行小字提示口令来源（启动服务时 `-admin-pass` 设的）

## 页面二：概览（登录后的首页）

- 四个统计位（全是真数据）：文章数（含草稿数）、总阅读、文章点赞、全站爱心
- 两个榜单：阅读最多 / 点赞最多，各 5 行（文章标题 + 次数，可点去文章）；空态文案
- 快捷动作：写新文章 / 管理文章 / 编辑站点数据
- 「重新构建站点」按钮 + 构建状态行的三种态：构建中… / 成功（耗时+时间）/ 失败（错误输出节选）
- 一段说明文案的位置（内容怎么生效：dev 热更新 / 部署后要构建 / 记得 git 提交）

## 页面三：文章列表

- 每行：标题、草稿徽标（草稿才有）、日期、slug（等宽字）、标签 chips、
  操作三枚：看（新窗口开文章）/ 编辑 / 删除
- 「写新文章」入口（页头）
- 空态（还没有文章）
- 删除需要确认（现在是浏览器 confirm，可以设计成弹层）

## 页面四：文章编辑器（新建与编辑同一页）

元信息区：
- 标题（单行，通栏）
- slug（等宽字；编辑已有文章时锁定不可改，新建时可填 + 格式提示）
- 日期、更新于（两个日期选择，更新于可空）
- 分类（单行，可空）、标签（逗号分隔）
- 摘要（两行文本域，可空）
- 「存成草稿」开关
- 封面：上传按钮 + 当前封面文件名（或「没有封面」）+ 「去掉封面」

正文区：
- Markdown 大文本域（等宽字）
- 「插入图片」按钮（传完自动插到光标处）
- Markdown 语法备忘一行
- 「保存」主按钮（支持 Ctrl+S）+「在站点里看」链接（编辑态才出现）
- 未保存离开的确认

## 页面五：站点数据

- 七个页签：最近在读 / 此刻 / 正在听 / 友链 / 项目 / 推荐分享 / 在用
- 每组一行说明（这块内容出现在站点哪里、注意事项）
- 条目卡：字段网格 + 每条的 上移 / 下移 / 删除
- 「添加一条」/「保存这一组」按钮
- 「正在听」页签多一块：音乐上传工具（选文件 → 显示得到的地址 → 复制）
- 切页签丢未保存改动的确认；至少保留 N 条的限制提示（项目、歌单）

各组字段（决定条目卡里有几个什么控件）：

| 组 | 字段 |
| --- | --- |
| 最近在读 | 书名、作者、进度%（数字）、进度条颜色（brand/gold 二选） |
| 此刻 | 顶部：更新日期、一句话、补充说明（多行）、移动端小字；条目：标签、内容、图标名、高亮开关 |
| 正在听 | 曲名、歌手、音频地址、歌词地址（可空） |
| 友链 | 站名、头像字、链接、域名、介绍（多行）、标签（逗号）、上线年份（数字）、渐变起/止/字色（三个取色器） |
| 项目 | 仓库、显示名、介绍（多行）、主语言、兜底星数（数字）、图标名、角标（可空）、最后推送时间 |
| 推荐分享 | 标题、链接、域名、介绍（多行）、图标名、配色（fire/leaf 二选）、分类 |
| 在用 | 名称、说明、图标名 |

## 通用件（画一版拼装用）

- 控件：单行输入、多行输入、下拉、日期、取色器、复选框；配套的字段标签 + 提示小字
- 按钮：主（深底）、次（描边）、危险（删除类）、条目小工具钮（上移/下移/删除）
- chips：标签、草稿徽标
- toast：成功 / 失败两种
- 状态：加载中、空态、「连不上数据服务」的报错（带启动指引）
- 顶栏：站名 + 「管理台」字样、三个导航项（当前态）、「打开站点」、「退出」
